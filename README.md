# SEATTLE STREETS

A small third-person neighborhood. Walk the sidewalks, drive the black SUV, and meet the people outside.

## Play

```bash
npm install
npm run dev
```

Open http://localhost:5173/. Press START on the title screen.

```bash
npm run build
```

## Controls

- WASD or arrow keys: move or drive
- Mouse: look (click the view first)
- Shift: sprint
- Space: jump
- F or Vehicle: enter or exit the black SUV when you are next to it
- J or Punch: punch. A nearby person stops for a moment
- 1 Wave, 2 Dance, 3 Laugh, 4 Sit. The Emote button cycles those poses
- Esc: pause

On a phone the view stays landscape, even if the device is portrait. Use the stick on the left and Punch, Emote, and Vehicle on the right.

## Settings

Music volume, sound effects volume, camera distance, and shadows. Settings are saved in this browser.
